## 1. 产品简介

本系统是一套**跨平台实时视频交互**方案，支持 Android 手机与 Web/电脑端双向投屏、多路画面合成、人像抠图、3D 场景展示与管理员角度控制，适用于全息投影演示、多机位采集、互动展览等场景。

### 主要能力

| 能力 | 说明 |
|------|------|
| 多设备同房间 | 多台手机/电脑加入同一房间，实时互通 |
| 双向投屏 | 手机推摄像头画面，电脑也可推屏/摄像头 |
| 3D 合成 | 多路画面在 3D 半圆场景中排列展示 |
| 人像抠图 | Web 与 Android 均支持 MediaPipe 实时抠图 |
| 管理员控制 | 调节各设备虚拟角度，向手机发送角度指引 |
| 全息输出 | 独立全屏窗口，可投到第二显示器/投影仪 |
| APK 在线更新 | 下载页自动同步版本，支持扫码安装 |

### 系统组成

```
┌─────────────┐     WebSocket      ┌──────────────┐
│ Web 客户端   │ ◄──────────────► │ 信令服务器    │
│ (浏览器/EXE) │     WebRTC P2P   │ (Node.js)    │
└─────────────┘ ◄──────────────► └──────────────┘
       ▲                                  ▲
       │         WebRTC P2P               │
       └──────────────┬───────────────────┘
                      │
              ┌───────▼────────┐
              │ Android 客户端  │
              └────────────────┘
```

## 2. 使用前准备

### 2.1 硬件要求

| 角色 | 最低要求 |
|------|----------|
| 电脑（管理/合成） | 4 核 CPU，8 GB 内存，支持 WebGL 的浏览器 |
| Android 手机 | Android 8.0+（API 26+），前后摄像头 |
| 网络 | 同一局域网，或已配置公网穿透 |

### 2.2 软件与服务

使用前需确保以下服务**已启动**：

```bash
cd holographic-system
npm run start          # 一键启动信令(9876) + Web(8080)
# 或分别启动：
npm run dev:server     # 信令服务器
npm run dev:client     # Web 客户端
```

**手机浏览器访问摄像头**需 HTTPS：

```bash
npm run start:https
```

### 2.3 权限说明

| 平台 | 所需权限 |
|------|----------|
| Web 浏览器 | 摄像头、麦克风（首次使用时授权） |
| Android | 摄像头、麦克风、网络、安装未知应用（仅 APK 安装时） |

## 3. 访问地址

### 3.1 局域网（默认）

| 服务 | 地址 | 说明 |
|------|------|------|
| Web 客户端 | `http://<电脑IP>:8080` | 浏览器打开 |
| 信令服务器 | `http://<电脑IP>:9876` | 一般无需直接访问 |
| WebSocket | `ws://<电脑IP>:9876/ws` | 客户端自动连接 |
| APK 下载页 | `http://<电脑IP>:8080/?page=download` | 含二维码 |
| APK 直链 | `http://<电脑IP>:9876/downloads/app-latest.apk` | 直接安装包 |

> 将 `<电脑IP>` 替换为运行服务的电脑局域网 IP，例如 `192.168.1.100`。

### 3.2 公网（frp 穿透示例）

若已配置 frp，将 `124.220.4.69` 替换为你的公网 IP：

| 服务 | 地址 |
|------|------|
| Web 客户端 | http://124.220.4.69:9001 |
| 信令服务器 | http://124.220.4.69:9000 |
| APK 下载页 | http://124.220.4.69:9001/?page=download&server=http://124.220.4.69:9000 |
| APK 直链 | http://124.220.4.69:9000/downloads/app-latest.apk |

## 4. Android 客户端下载与安装

### 4.1 下载方式

**方式一：扫码下载（推荐）**

1. 用电脑或手机浏览器打开 [APK 下载页](http://124.220.4.69:9001/?page=download&server=http://124.220.4.69:9000)
2. 扫描页面上的二维码
3. 点击「下载 APK」

**方式二：直接下载链接**

```
http://124.220.4.69:9000/downloads/app-latest.apk
```

**方式三：加入页入口**

Web 加入页底部点击 **「下载 Android 客户端」**。

### 4.2 安装步骤

1. 下载完成后点击安装包
2. 若提示「未知来源」，进入系统设置 → 允许此来源安装应用
3. 完成安装后打开 **「全息投影 · 手机端」**

### 4.3 检查更新

- App 启动时会**自动检查**是否有新版本
- 也可在加入页点击 **「检查更新」** 手动检查
- 下载页每 30 秒自动刷新版本信息

### 4.4 当前版本

访问以下地址查看实时版本：

```
http://124.220.4.69:9000/api/app/version
```

返回 `"available": true` 且含 `downloadUrl` 时表示可下载。

## 5. Web / 电脑端使用

### 5.1 加入房间

1. 浏览器打开 Web 客户端地址
2. 填写表单：

| 字段 | 说明 |
|------|------|
| 信令服务器 | 默认自动填充；公网使用时填 `http://124.220.4.69:9000` |
| 房间号 | 留空则自动创建；加入已有房间则输入房间号（如 `ABC123`） |
| 设备名称 | 显示在设备列表中，可自定义 |
| 设备类型 | 选「电脑」或「手机」 |
| 以管理员身份加入 | 勾选后可使用角度控制等管理功能 |
| 开启人像抠图 | **加入房间前**勾选；推流时使用绿幕传输，接收端自动抠图 |

> **抠图说明**：WebRTC 不支持透明通道，系统采用**绿幕 + 接收端色键**方案。采集端（手机/Web）开启抠图后，3D 显示端会自动去除绿色/黑色背景。

3. 点击 **「进入房间」**

### 5.2 邀请其他设备

进入房间后，左侧显示 **房间二维码** 和房间号。其他设备可：

- 扫描 QR 码（自动填入房间号与信令地址）
- 手动输入房间号加入

### 5.3 投屏与订阅

**本机推流：**

1. 点击 **「摄像头投屏」** 开始推送摄像头画面
2. 电脑端还可点击 **「屏幕+摄像头」** 同时推送屏幕

**观看其他设备：**

1. 在左侧 **设备列表** 中找到目标设备
2. 点击 **「订阅」** 接收其画面
3. 订阅后画面出现在 3D 视图或网格视图中

**停止投屏：** 点击 **「停止投屏」**

### 5.4 工具栏功能

| 按钮 | 功能 |
|------|------|
| 3D / 浮雕 / 点云 / 网格 / 立体对 | 切换视图模式（见第 8 节） |
| 虚实融合 | 开启后叠加本机背景摄像头画面 |
| 管理员模式 | 切换管理员/普通用户身份 |
| 全息输出 | 新窗口全屏输出，适合投影仪 |

### 5.5 性能监控

右侧面板显示：

- 各连接码率、帧率、丢包率
- 信令延迟（ms）
- 弱网时系统自动 **降质**（降低分辨率/帧率）

### 5.6 3D 视图操作

- **鼠标拖拽**：旋转视角
- **滚轮**：缩放
- 多设备订阅后，画面按半圆排列在 3D 空间中

## 6. Android 手机端使用

### 6.1 加入房间

**手动加入：**

1. 打开 App，输入房间号（如 `ABC123`）
2. 点击 **「加入房间」**

**扫码加入：**

1. 点击 **「扫码加入」**
2. 扫描 Web 端左侧的房间二维码
3. 也支持扫描含 `room=` 参数的完整 URL

### 6.2 开始投屏

1. 成功加入房间后，底部出现控制栏
2. 可选开启 **「人像抠图」**
3. 点击 **「开始投屏」** 推送摄像头画面
4. 电脑端在设备列表中 **订阅** 即可看到手机画面

### 6.3 角度指引

管理员从电脑端发送角度指引后，手机屏幕上显示 **罗盘箭头**，提示调整手机 yaw/pitch 角度。请按指引旋转手机。

### 6.4 状态栏

顶部状态栏显示：

- 当前房间号
- 信令延迟（ms）

## 7. 管理员功能

> 加入时勾选「以管理员身份加入」，或进入房间后点击「管理员模式」。

### 7.1 角度控制

底部 **管理员面板** 提供：

| 控制项 | 说明 |
|--------|------|
| Yaw | 水平旋转角（0°–360°） |
| Pitch | 俯仰角 |
| Roll | 翻滚角 |
| 发送角度指引 | 向指定手机发送罗盘指引 |
| 保存当前 | 保存当前 3D 布局为场景方案 |
| 加载方案 | 从下拉列表恢复已保存方案 |

### 7.2 典型工作流

```
创建房间(管理员) → 手机加入并投屏 → 电脑订阅
    → 调节各设备角度 → 保存场景 → 全息输出到投影仪
```

## 8. 多屏显示端（全息输出）

「显示端」不是单独的设备类型，而是**第二台电脑/浏览器**，专门用于投影仪或第二显示器全屏展示合成画面。

### 8.1 三端分工

| 角色 | 设备 | 职责 |
|------|------|------|
| **采集端** | Android 手机 / Web 选「手机」 | 摄像头投屏、可选抠图 |
| **控制端** | Web 选「电脑」+ 管理员 | 订阅画面、调节 3D 角度、保存场景 |
| **显示端** | Web 全息窗口 / 第二浏览器 | 全屏展示 3D/立体对画面，无操作 UI |

### 8.2 推荐流程

```
控制端建房间(管理员) → 手机加入并投屏 → 控制端订阅并调角度
    → 控制端点「全息输出」→ 显示端自动加入、自动订阅 → 投影仪全屏
```

### 8.3 方式一：一键全息输出（推荐）

1. 在**控制端**完成订阅和 3D 布局调节
2. 点击工具栏 **「全息输出」**
3. 新窗口即为**显示端**，会：
   - 自动加入同一房间（设备名：全息显示端）
   - **自动订阅**所有在线采集端
   - 隐藏侧栏/管理 UI，默认 **立体对** 视图
4. 将新窗口拖到投影仪，按 **F11** 全屏

### 8.4 方式二：手动打开显示端 URL

```
http://124.220.4.69:9001/?hologram=1&room=ABC123&server=http://124.220.4.69:9000&view=stereo&type=desktop&name=全息显示端
```

| 参数 | 说明 |
|------|------|
| `hologram=1` | 启用显示端模式 |
| `room` | 房间号（必填） |
| `server` | 信令服务器地址 |
| `view` | 视图：`3d` / `stereo` / `relief` / `pointcloud` / `grid` |
| `name` | 显示端设备名 |

### 8.5 显示端注意事项

- 显示端**不需要**勾选管理员，也**不需要**手动点订阅
- 3D 布局（角度/位置）由控制端调节，通过信令 **mapping_sync** 自动同步到显示端
- 若显示端无画面：确认采集端已「开始投屏」，且与控制端在同一房间
- 立体对模式适合偏振 3D 投影仪；普通投影可用 `view=3d`

## 10. 公网访问（frp 穿透）

### 9.1 架构

```
用户浏览器/App
      │
      ▼
公网 IP:9000 (信令)  ──frp──►  本机:9876
公网 IP:9001 (Web)    ──frp──►  本机:8080
```

### 9.2 使用前确认

1. 本机信令服务运行在 **9876** 端口
2. 本机 Web 客户端运行在 **8080** 端口
3. frpc 客户端已连接，两个代理均为 **proxy success**
4. 公网访问测试：

```bash
curl http://124.220.4.69:9000/health
curl http://124.220.4.69:9001/
```

### 9.3 注意事项

- Web 端公网访问填信令地址：`http://124.220.4.69:9000`
- Android APK 内置信令地址需与公网地址一致（修改 `SignalingConfig.kt` 后重新构建）
- 手机浏览器使用摄像头仍需 **HTTPS**；使用 APK 则不受此限制

## 11. 常见问题

### Q1：手机浏览器无法打开摄像头？

**原因**：非 HTTPS 环境下浏览器限制摄像头权限。  
**解决**：
- 使用 `npm run start:https` 启动 HTTPS 模式
- 或改用 Android APK（推荐）

### Q2：设备列表看不到其他设备？

**检查**：
1. 是否在同一房间号
2. 信令服务器地址是否一致
3. 信令延迟是否显示「重连中...」
4. 防火墙是否放行 9876 端口

### Q3：画面卡顿或模糊？

- 查看右侧性能面板丢包率
- 系统弱网时会自动降质
- 建议同一局域网内测试，或配置 TURN 服务器（见 [DEPLOYMENT.md](./DEPLOYMENT.md)）

### Q4：APK 下载页显示「暂无安装包」？

**原因**：服务器尚未发布 APK。  
**解决**（管理员）：

```bash
cd holographic-system/android
./gradlew assembleDebug
cd ..
bash scripts/publish-apk.sh debug "更新说明"
```

### Q5：扫码后无法加入房间？

- 确认 QR 码未过期（重新进入房间生成新码）
- Android 扫码支持：纯房间号、含 `room=` 的 URL
- 检查信令服务器是否可达

### Q6：3D 视图空白？

- 确认已 **订阅** 至少一台正在投流的设备
- 确认对方已点击「开始投屏/摄像头投屏」
- 尝试切换到「网格」模式验证画面是否正常

### Q8：抠图不生效，背景仍是绿色或黑色？

1. **加入前**勾选「开启人像抠图」（Web）或打开抠图开关（Android）
2. 接收端（控制端/显示端）需 **订阅** 该设备，3D 视图才会色键抠图
3. Web 端 MediaPipe 首次加载需数秒，请稍等再投屏
4. Android 需更新至 **v0.1.2+**（绿幕抠图）

### Q7：App 打开全黑屏、看不到任何按钮？

**原因**：旧版 v0.1.0 中 WebRTC 预览层遮挡了加入页。  
**解决**：更新至 **v0.1.1** 或更高版本（下载页 / 检查更新）。
